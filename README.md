# LOSS MODEL · 损失模型交互式教学站

英国精算师 IFoA **CS2（Risk Modelling & Survival Analysis）** 课程配套的互动教学站，纯前端静态页面，无需登录服务器、无需构建。

**🧪 主入口 · 学习舱 V3（账号版）：https://mathzhm.github.io/loss-model/lab3/**

## 🧪 学习舱 V3（lab3/，当前主力）

覆盖 10 章（Ch13–22）**52 个知识点、52 段讲解视频、52 个互动演示、468 题自测**：

- **课程地图首页**：四步学习路线（打地基 → 单笔损失 → 风险组合 → 现代工具箱）串联 10 章，附 IFoA 官方大纲对照带
- **六步学习页**：看讲解 → 看图解 → 抓直觉 → 串链条 → 动手玩 → 通关自测
- **账号与学习记录**：自选昵称/学号（建议学号）+ 可选口令，步骤级学习记录与错题本存本机浏览器
- **错题本 / 竞技场 / 演示库**：错题重做、限时连击挑战、52 个演示按章检索
- **学习地图**：进度总览、52 知识点明细、一键导出/导入备份 JSON
- **教师端**（仅本地，不上传服务器）：导入学生导出的 JSON 生成汇总报表与 CSV

### 学生使用三句话

1. 打开 https://mathzhm.github.io/loss-model/lab3/ ，输入**学号**创建账号（公用电脑建议设口令）；
2. 学习过程中进度自动保存，但**只存在这台电脑的浏览器里**——定期在「学习地图」点「⬇ 导出学习记录」备份；
3. 换电脑或误清数据？用导出的 JSON「⬆ 导入备份」即可恢复。

## 🔒 隐私与数据

- 所有学习数据（进度、错题、掌握度画像）**仅存于学生浏览器本地（localStorage）**，本站为纯静态页面，不上传、不收集任何数据；
- 账号为学生自选昵称/学号，不要求真名；
- 跨设备同步受纯静态托管限制，记录流转采用「学生导出 JSON → 教师本机导入汇总」。
