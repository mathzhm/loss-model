# LOSS LAB V3 · 损失模型 · CS2 互动学习舱（账号版）

英国精算师 IFoA CS2（Risk Modelling & Survival Analysis）课程学习站 · 简洁清晰的课程地图式 UI。

**双击 `index.html` 即可离线运行**（纯 HTML + 原生 JS，零构建、零依赖）。

## 页面导览

| 页面 | 说明 |
|---|---|
| index.html | **首页 = 课程地图**：一句话说清课程主线，四步学习路线（STAGE 1-4）串联 10 章；章节默认收起，点卡片展开知识点，支持「全部展开」；每章显示已学进度；附 IFoA 官方大纲对照带 |
| `learn.html?ch=17&kp=joint-marginal` | **学习页**：顶排步骤按钮切换内容（01 看讲解 → 02 看图解 → 03 抓直觉 → 04 串链条 → 05 动手玩 → 06 通关自测），左侧为本章知识点选择栏 + 学习资料（PDF/QA）；自测答错自动进错题本 |
| map.html | **学习地图（进度页）**：账号化进度总览、继续学习、十章双色进度条、52 知识点学习明细、导出/导入学习记录 JSON |
| wrong.html | **错题本**：按章筛选、单题重做（答对自动移出）、清空 |
| arena.html | **竞技场**：选题范围与题数，60 秒限时，连击加分，结算页；错题自动入本 |
| library.html | **演示库**：52 个互动演示，按章浏览 + 关键词搜索 |

### teacher.html（仅本地，不上传 GitHub）

教师端为独立本地页面：导入学生导出的 JSON 汇总报表、逐知识点明细、CSV 导出。**数据不出本机。**

- 不随仓库 / GitHub Pages 发布，学生无法在线访问；
- 在本机打开的站点门禁输入教师账号名（默认 `Minz`）即可直达教师端，需再输教师口令；
- 教师口令在 `teacher.html` 源码顶部 `TEACHER_PASS` 处修改。

## 数据与记录

- `course.js` 是唯一内容数据源（10 章 52 知识点、468 题自测、52 段讲解视频、52 个互动演示）。
- 账号体系（本机 localStorage，纯静态托管无后端）：
  - `v3accounts` 账号列表（自选昵称/学号 + 可选口令）
  - `v3cur` 当前账号
  - `v3data_<账号名>` 该账号的步骤级学习记录与错题本
- 纯静态托管做不到跨设备同步：记录流转 = 学生「导出 JSON」→ 教师端导入汇总；学生换机/误清数据可用之前导出的 JSON 导入恢复。
- 共享顶栏、账号门禁与存取在 `nav.js`。
