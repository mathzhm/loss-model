广义线性模型(GLM)指南

连接函数选择与映射机制详解

1. 不同分布对应的连接函数选择

广义线性模型通过连接函数将线性预测项与响应变量的均值联系起来。选择合适的连接函数取决于响应变量的分布类型。

分布类型 典型应用场景 连接函数 连接函数表达式 均值函数
正态分布 连续数据，如身高、温度 恒等连接 g(μ) = μ μ = η
泊松分布 计数数据，如事件发生次数 对数连接 g(μ) = log(μ) μ = exp(η)
二项分布 二元结果，如成功/失败 Logit连接 g(μ) = log(μ/(1-μ)) μ = exp(η)/(1+exp(η))
伽马分布 正连续数据，如等待时间 逆连接 g(μ) = 1/μ μ = 1/η
负二项分布 过度离散的计数数据 对数连接 g(μ) = log(μ) μ = exp(η)

选择原则：

  • 规范性：连接函数应确保预测值在响应变量的合理范围内
  • 可解释性：连接函数应便于模型结果的解释
  • 统计性质：应选择能提供良好统计性质的连接函数

2. 连接函数的映射机制

连接函数的核心作用是将线性预测项 η 映射到响应变量的均值 μ。

GLM基本结构：
g(μ) = η = β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ
其中：μ = E(Y|X)，η 是线性预测项，g(·) 是连接函数

映射过程详解：

1

线性预测

计算线性组合 η = Xβ

2

连接函数应用

通过连接函数 g(μ) = η

3

均值转换

得到均值 μ = g⁻¹(η)

4

响应生成

Y ~ 指定分布(μ)

具体示例：Logit连接函数（逻辑回归）

连接函数： g(μ) = log(μ/(1-μ))

逆连接函数： μ = 1/(1+exp(-η))

映射过程：

  1. 计算线性预测项：η = β₀ + β₁X₁ + ...
  2. 应用连接函数：log(μ/(1-μ)) = η
  3. 求解均值：μ = exp(η)/(1+exp(η))
  4. 确保 μ 始终在 [0,1] 范围内

关键数学性质：

连接函数必须满足：
1. 可逆性：存在逆函数 g⁻¹(·)
2. 单调性：保持顺序关系
3. 定义域匹配：确保 μ 在合理范围内

总结

广义线性模型通过连接函数巧妙地将线性模型的简洁性与各种非正态分布数据的特性结合起来。正确选择连接函数是GLM成功应用的关键，它确保了模型预测的合理性和可解释性。

核心要点：

  • 连接函数的选择取决于响应变量的分布类型
  • 连接函数将线性预测项映射到响应变量均值
  • 映射过程通过连接函数的逆函数实现
  • 合适的连接函数确保预测值在合理范围内
