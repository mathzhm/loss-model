原理讲解

右审查（right censoring）是生存数据与损失数据的常态：保单在到期时仍未出险（只知道「超过保期」）、病人在研究结束时仍存活、赔款被分层限额截断。审查观测不是废数据——它携带了「寿命至少超过 c」的信息，扔掉它必然产生系统性偏差。

对 Exp(λ) 做似然：未审查观测贡献密度 λe−λt；审查观测贡献生存概率 S(c)=e−λc（「超过 c」的概率）。设 d = 未审查个数、T = Σ min(ti, c)（总「暴露时间」），则：

ℓ(λ) = d·ln λ − λ·T  ⟹  λ̂ = d / T（完整似然 MLE，无偏且有效）

朴素做法错在哪：只拿未审查的 d 个数算 λ̃ = d / Σ(未审查的 ti)。未审查观测天然偏「短命」（长的全被 c 截走了），分母被压小，λ̃ 系统性偏大 → 低估寿命。审查越严重（c 越小），偏得越离谱。

操作建议：拖小 c（如 1.5）看左图审查比例飙升、两个蓝点分道扬镳；再点「重复 300 次实验」——右图中 λ̃ 的分布整体右移（偏差 = 均值 − 真实 λ），而 λ̂ 的分布稳定骑在真实值上。把 c 拉大（如 8）——几乎无审查，两个估计重合：偏差随审查强度单调恶化，这就是「删掉的观测也在说话」的含义。

与课程的联系：Kaplan–Meier 估计、 Cox 模型、以及 Ch20 的参数不确定性讨论，全部建立在「审查观测贡献似然中的生存概率」这一基石上——本页的 λ̂ = d/T 正是它最干净的特例。
