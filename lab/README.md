# LOSS LAB · 损失模型实验舱

> CS2（Risk Modelling & Survival Analysis）互动学习平台
> 把抽象的损失模型变成**可以拖、可以玩、可以闯关**的实验。

面向大三精算生。单一数据源驱动，零依赖（纯 HTML + 原生 JS + Canvas），双击 `index.html` 即可离线运行。

## 🗂 架构：为什么这样设计

三个前身各有所长，也各有短板：

| 前身 | 优点 | 短板 |
|------|------|------|
| 49 个独立 demo | 有真实数学模拟 | 各自为政，无路径、无游戏、无闭环 |
| Genspark 8 站 | 教学法深（机制链、渐进披露、侦探游戏） | 每站定制 4 万字，**不可扩展**（只做出 2 站） |
| high-school 四页 | 单数据源、结构清晰、好维护 | 内容薄，没有互动实验 |

**LOSS LAB 的解法：造少量可复用的"实验引擎"，用一个数据文件去配置它们。**
一个引擎服务几十个知识点 → 铺满整门课，还保持统一体验 + 游戏层。

```
course.js   ← 唯一数据源：10 章 → 知识点 → (情境/讲解/直觉/机制链/引擎配置/抽屉/自测)
   │            └─ COURSE.lectures：每个知识点的讲解映射（视频+概念图+导读）
   │
   ├─ index.html    课程地图门户（示波器动画 + 进度仪表 + 章节卡片 + 成就）
   ├─ learn.html    学习视图（情境钩子→讲解→机制链→实验台→渐进披露→通关自测）
   ├─ library.html  演示库（课程框架外的拓展互动演示，页内 iframe 打开）
   ├─ arena.html    竞技场（限时连击 / 精算侦探 / 配对冲刺）
   └─ wrong.html    错题本（按章分组 / 重做 / 导出 CSV）
   │
video/      ← Min 讲稿视频（61 个，约 304MB；37 个为逐知识点专属讲解，其余为章节共用）
img/        ← 精选概念图（64 张，约 89MB，含 16 张系列概念图与专题图解）
engine.js   ← 10 个可复用实验引擎（零依赖 Canvas）
game.js     ← 游戏化闭环（XP/等级/连击/徽章/连续天数/错题本）
style.css   ← 统一设计系统（深蓝实验舱 + 坐标纸网格 + 九章彩色）
```

**页面不存内容，只负责渲染。** 加章节、加知识点、改题目，都只动 `course.js`。

## 🔬 十个实验引擎

| 引擎 | 交互 | 服务的知识点（例） |
|------|------|------|
| `curve` | 拖参数 → 曲线实时变形 | 分布图鉴、GEV 尾型、再保险自留/分出、Ridge/LASSO 收缩路径、GLM 方差函数 V(μ)/连接函数 g(μ)、逆变换 CDF |
| `scatter` | 切换 copula 家族 + 拖 θ/ρ/ν → 散点抱团 + τ/λ 读数 | Copula 家族、Sklar 解耦、椭圆族 |
| `tsSim` | 拖 φ/θ → 模拟序列 + 样本 ACF 实时重算 | AR(1)/MA(1)/AR(2)、随机游走、平稳性 |
| `compound` | 拖 λ/强度 → 聚合赔款 S 的 MC 直方图 + E[S]/VaR | 集体风险模型、复合 Poisson |
| `ruin` | 拖 u/c → 盈余路径群，破产路径变红 + ψ̂ 读数 | Cramér-Lundberg 破产模型 |
| `match` | 拖拽概念 ↔ 定义配对 | Box-Jenkins、评估指标、K-means/PCA |
| `build` | 拖积木拼装公式 | 二阶差分、复合分布方差 |
| `predict` | 先下注再揭示 | 通胀杠杆、协整、Bagging vs Boosting |
| `hist` | 拖参数看 PIT 把分布“洗”成均匀 | 概率积分变换 |
| `aggregate` | 蒙特卡洛对比不同 copula 的 VaR | 聚合损失与资本 |

引擎读 `course.js` 里的声明式配置（函数名走注册表，不 eval），**新增一类可视化 = 在 engine.js 注册一个函数**。

## ✏️ 如何加一个知识点（3 步）

1. 打开 `course.js`，找到目标章节的 `kps` 数组。
2. 粘一个知识点对象（照抄现有结构）：
   ```js
   { id:"xxx", name:"知识点名", icon:"📌", minutes:8,
     hook:"情境故事（先于公式）",
     intuition:"直觉层讲解",
     chain:{ param:{lab,val,sub}, math:{...}, real:{...} },   // 三层机制链
     engine:{ type:"curve", ... },                             // 引擎配置（可选）
     drawers:{ mechanism:"…", math:"…", code:"…" },           // 渐进披露（可选）
     quiz:[ {q,opts:[4],ans:0,why:"解析",lv:1} ] }            // 自测（lv=1简单/2中等/3困难，答错进错题本）
   ```
3. 保存刷新。地图、学习页、竞技场题库、错题本**全部自动更新**。

加一整章同理：在 `chapters` 数组加一个对象，`status:"live"` 即点亮，`"soon"` 显示为建设中。

### 公式书写规范（零依赖渲染，不用 LaTeX）

平台不引 MathJax/KaTeX（保持零依赖、离线可用，且 Canvas 实验台用不了 LaTeX），公式统一用 **Unicode + HTML `<sub>`/`<sup>`** 书写，规则：

- **大写字母下角标用 HTML**（保留大小写）：`F<sub>X</sub>(x)`、`ρ<sub>S</sub>`、`λ<sub>L</sub>`、`e<sub>X</sub>(M)`——随机变量/统计量下标必须大写。
- **数字与小写字母下角标用 Unicode**：`φ₁`、`Xₜ`、`xᵢ`、`ρₖ`（Canvas 内外都能显示）。
- **上标同理**：`x²`、`φʰ`（数字/小写 Unicode），`e<sup>−λX</sup>`、`Σᵢ₌₁<sup>N</sup>`（含大写/复杂用 HTML）。
- **R 代码块（`code:"..."`）保持原样**，`x^3`、`X_t` 是合法语法不转换。

渲染端：正文/抽屉/live 值/图例/题干/解析走 `innerHTML`；**quiz 选项与竞技场配对接 `escMath()`**（先转义保护裸 `<`/`>` 运算符如「指数 < 对数正态」，再放行 `<sub>`/`<sup>` 标签）；**build 积木与 match 配对**用 `innerHTML` + `dataset.raw` 比对（带下标的积木如 `F<sub>Y</sub>(y)` 正常渲染且答案校验正确）。给新知识点写公式照此规范即可。

## ✅ 质量说明

核心数学公式已用独立脚本交叉验证（2026-07）：
Clayton λ(q)→λ_L 收敛、Clayton/Gumbel/Gaussian 的 Kendall τ、Gumbel λ_U、
Frank τ（Debye 积分）、GEV 密度归一、Gamma 密度归一——全部通过。

> 修过一个真实 bug：gammaln 初版混用了两套 Lanczos 系数表，导致 Gamma 密度与
> t-copula（经 betai/tCDF）失真，已修正并复验。
