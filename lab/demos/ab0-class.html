(a,b,0)类分布理论与应用

递推公式、分布识别、可加性与可分解性的深入探索

1. (a,b,0)类分布递推公式

基本递推关系：
$$\frac{p_k}{p_{k-1}} = a + \frac{b}{k}, \quad k = 1, 2, 3, \ldots$$

其中 $p_k = P(X = k)$ 是概率质量函数，$a$ 和 $b$ 是分布的特征参数。

3. 泊松分布的可加性与可分解性

可加性 (Additivity)

$$X_1 \sim \text{Poisson}(\lambda_1), \quad X_2 \sim \text{Poisson}(\lambda_2)$$ $$X_1 + X_2 \sim \text{Poisson}(\lambda_1 + \lambda_2)$$

证明思路：使用概率生成函数

$$G_{X_1+X_2}(z) = G_{X_1}(z) \cdot G_{X_2}(z) = e^{\lambda_1(z-1)} \cdot e^{\lambda_2(z-1)} = e^{(\lambda_1+\lambda_2)(z-1)}$$

可分解性 (Decomposability)

$$X \sim \text{Poisson}(\lambda) \Rightarrow X = X_1 + X_2$$ $$X_1 \sim \text{Poisson}(\lambda_1), \quad X_2 \sim \text{Poisson}(\lambda_2)$$ $$\text{其中 } \lambda_1 + \lambda_2 = \lambda$$

4. 负二项分布的混合泊松表示

混合泊松模型：
$$X|\Lambda \sim \text{Poisson}(\Lambda)$$ $$\Lambda \sim \text{Gamma}(r, \beta)$$ $$\Rightarrow X \sim \text{NegativeBinomial}(r, p)$$

其中 $p = \frac{\beta}{\beta + 1}$，$r$ 可以是非整数。

r为非整数的情形

当 $r$ 不是正整数时，负二项分布仍然有意义：

$$P(X = k) = \binom{k+r-1}{k} p^r (1-p)^k$$ $$\text{其中 } \binom{k+r-1}{k} = \frac{\Gamma(k+r)}{\Gamma(r)\Gamma(k+1)}$$

混合泊松到负二项分布转换

5. 二项分布的近似

泊松近似

$$\text{当 } n \to \infty, p \to 0, np = \lambda \text{ 时}$$ $$\text{Binomial}(n, p) \approx \text{Poisson}(\lambda)$$

适用条件：$n \geq 30$，$p \leq 0.1$，$np \leq 5$

正态近似

$$\text{当 } n \text{ 足够大时}$$ $$\text{Binomial}(n, p) \approx \text{Normal}(np, np(1-p))$$

适用条件：$np \geq 5$ 且 $n(1-p) \geq 5$
