广义线性模型 (GLM) 综合学习模块

1. 线性回归与广义线性模型的数理基础

1.1 线性回归模型

线性回归是统计学中最基础的模型之一，它假设响应变量与预测变量之间存在线性关系。

数学表达式：

Y = Xβ + ε
其中：
- Y 是响应变量（因变量）
- X 是预测变量（自变量）矩阵
- β 是待估计的参数向量
- ε 是误差项，假设服从正态分布 N(0, σ²I)

核心假设：

  • 响应变量分布：假设响应变量 Y 服从正态分布
  • 连接函数：恒等函数（identity function），即 E(Y) = μ = Xβ
  • 方差结构：假设方差为常数（同方差性），即 Var(Y) = σ²
  • 误差独立性：各观测的误差项相互独立

1.2 广义线性模型(GLM)

广义线性模型是线性回归的扩展，它放宽了线性回归的一些限制性假设，使模型能够适应更广泛的数据类型。

数学表达式：

g(μ) = Xβ
其中：
- μ = E(Y) 是响应变量的期望
- g(·) 是连接函数
- X 是预测变量矩阵
- β 是待估计的参数向量
- Y 服从指数族分布

核心组成部分：

  • 随机分量：响应变量 Y 服从指数族分布（如正态分布、二项分布、泊松分布等）
  • 系统分量：线性预测器 η = Xβ
  • 连接函数：g(μ) = η，连接响应变量的期望与线性预测器

1.3 核心区别对比

特性 线性回归 广义线性模型(GLM)
响应变量分布 仅限正态分布 可以是指数族中的任何分布（正态分布、二项分布、泊松分布、伽马分布等）
连接函数 恒等函数（identity）：g(μ) = μ 可以是多种函数：logit、log、probit、inverse等
方差结构 同方差性：Var(Y) = σ²（常数） 方差可以是均值的函数：Var(Y) = V(μ)φ
预测值范围 无限制（可以是任何实数） 可以限制在特定范围（如概率在[0,1]之间）
参数估计方法 最小二乘法（OLS） 最大似然估计（MLE）或迭代加权最小二乘法（IWLS）

2. 计数数据与比例数据的特点

2.1 计数数据

计数数据是指对事件发生次数的统计，只能取非负整数值。

主要特点：

  • 只能取非负整数值（0, 1, 2, 3, ...）
  • 数据通常呈现右偏分布（非对称）
  • 方差往往与均值相关，不满足同方差假设
  • 不适合用正态分布建模
  • 常见例子：疾病发生次数、交通事故数、网站访问量等

计数数据通常可以用泊松分布或负二项分布建模。泊松分布假设均值等于方差，而负二项分布则适用于过度离散（方差大于均值）的情况。

2.2 比例数据

比例数据是指取值范围在0到1之间的数据，通常表示某种比例、概率或百分比。

主要特点：

  • 取值范围有限，通常在[0,1]区间内
  • 数据分布通常在0和1附近聚集，呈现双峰或U形分布
  • 方差不恒定，与均值相关（接近0或1时方差较小）
  • 不适合用正态分布建模
  • 常见例子：投票比例、成功率、市场份额等

比例数据通常可以用Beta分布建模，或者当数据来源于二项试验时，可以用二项分布建模。

3. 线性回归与GLM在处理计数数据和比例数据的对比

3.1 处理计数数据

3.1.1 线性回归处理计数数据

方法：直接将计数作为因变量，使用普通最小二乘法估计参数。

优点：

  • 模型简单，易于理解和解释
  • 计算效率高
  • 当计数值较大且分布接近对称时，可能表现尚可

缺点：

  • 可能预测出负值，违背计数数据非负的本质
  • 无法正确建模方差与均值的关系（计数数据通常方差随均值增加而增加）
  • 对于小计数和零膨胀数据表现不佳
  • 违背正态性和同方差性假设

3.1.2 GLM处理计数数据（泊松回归）

方法：假设响应变量服从泊松分布，使用对数连接函数。

log(μ) = Xβ
其中 Y ~ Poisson(μ)

优点：

  • 保证预测值为非负数
  • 正确建模了计数数据的离散性
  • 捕捉了方差与均值成比例的特性（泊松分布中 Var(Y) = E(Y)）
  • 对小计数和稀疏数据表现良好

缺点：

  • 泊松分布假设方差等于均值，无法处理过度离散或欠离散的数据
  • 无法直接处理零膨胀问题（过多的零值）
  • 需要使用最大似然估计，计算复杂度较高

扩展：对于过度离散的计数数据，可以使用负二项GLM；对于零膨胀数据，可以使用零膨胀泊松模型或零膨胀负二项模型。

3.2 处理比例数据

3.2.1 线性回归处理比例数据

方法：直接将比例作为因变量，使用普通最小二乘法估计参数。

优点：

  • 模型简单，易于理解和解释
  • 计算效率高
  • 当比例接近0.5且样本量大时，可能表现尚可

缺点：

  • 可能预测出超出[0,1]范围的值
  • 无法正确建模边界效应（当均值接近0或1时）
  • 无法处理方差随均值变化的特性
  • 对于极端比例（接近0或1）表现不佳

3.2.2 GLM处理比例数据（逻辑回归/Beta回归）

方法1：逻辑回归（适用于二项比例数据，如成功/失败次数）

logit(μ) = log(μ/(1-μ)) = Xβ
其中 Y ~ Binomial(n, μ)

方法2：Beta回归（适用于连续比例数据）

logit(μ) = Xβ
其中 Y ~ Beta(a, b)，且 E(Y) = μ = a/(a+b)

优点：

  • 保证预测值在[0,1]范围内
  • 正确建模边界效应（logit变换处理0和1附近的非线性关系）
  • 可以处理方差与均值的非恒定关系
  • 对极端比例数据表现良好

缺点：

  • 参数解释不如线性回归直观（需要进行逆变换）
  • 计算复杂度较高
  • Beta回归无法直接处理0和1的精确值（需要进行数据变换）

4. 实际应用案例对比

4.1 计数数据案例：疾病发生次数预测

模型 数学表达式 预测结果特点 适用场景
线性回归 疾病次数 = β₀ + β₁×年龄 + β₂×性别 + ... 可能出现负值；预测值为连续数 大样本、计数值较大且分布接近正态时
泊松回归(GLM) log(疾病次数) = β₀ + β₁×年龄 + β₂×性别 + ... 预测值始终为非负数；能反映稀有事件特性 小样本、低计数值、方差接近均值的情况
负二项回归(GLM扩展) log(疾病次数) = β₀ + β₁×年龄 + β₂×性别 + ... 预测值为非负数；能处理过度离散现象 数据方差明显大于均值的情况

4.2 比例数据案例：选民投票意向预测

模型 数学表达式 预测结果特点 适用场景
线性回归 投票比例 = β₀ + β₁×年龄 + β₂×收入 + ... 预测值可能超出[0,1]范围；边界处表现差 比例接近0.5且变化不大的情况
逻辑回归(GLM) log(p/(1-p)) = β₀ + β₁×年龄 + β₂×收入 + ... 预测值严格在[0,1]范围内；边界处表现好 二项比例数据（成功/失败次数）
Beta回归(GLM扩展) logit(μ) = β₀ + β₁×年龄 + β₂×收入 + ... 预测值在(0,1)范围内；能处理U形或J形分布 连续比例数据，尤其是分布在0和1附近聚集的情况

5. 总结

线性回归和广义线性模型在处理不同类型数据时各有优缺点：

数据类型 线性回归 广义线性模型(GLM) 推荐模型
连续数据（正态分布） ✓ 最佳选择 ✓ 可用（等同于线性回归） 线性回归
计数数据 ✗ 不适合（可能预测负值） ✓ 适合（泊松/负二项回归） 泊松GLM或负二项GLM
二项比例数据 ✗ 不适合（预测值可能超出范围） ✓ 适合（逻辑回归） 逻辑回归(GLM)
连续比例数据 ✗ 不适合（边界效应处理不当） ✓ 适合（Beta回归） Beta回归(GLM扩展)

核心结论：广义线性模型通过灵活的分布假设和连接函数，能够更准确地建模非正态数据，特别是计数数据和比例数据。线性回归虽然简单直观，但在处理这些特殊数据类型时存在明显局限性。在实际应用中，应根据数据特性选择合适的模型。
