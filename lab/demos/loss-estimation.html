损失估计理论与应用

点估计、估计质量评价与区间估计的交互式学习平台

1. 矩估计 (Method of Moments)

基本思想：
$$\text{样本矩} = \text{总体矩}$$ $$\frac{1}{n}\sum_{i=1}^n X_i^k = E[X^k] = \mu_k(\theta)$$

通过令样本矩等于总体矩来求解参数估计值。

矩估计计算器

指数分布矩估计

$$f(x) = \lambda e^{-\lambda x}, \quad x \geq 0$$ $$E[X] = \frac{1}{\lambda} \Rightarrow \hat{\lambda} = \frac{1}{\bar{X}}$$

伽马分布矩估计

$$f(x) = \frac{\beta^\alpha}{\Gamma(\alpha)} x^{\alpha-1} e^{-\beta x}$$ $$E[X] = \frac{\alpha}{\beta}, \quad \text{Var}[X] = \frac{\alpha}{\beta^2}$$ $$\hat{\alpha} = \frac{\bar{X}^2}{S^2}, \quad \hat{\beta} = \frac{\bar{X}}{S^2}$$

帕累托分布矩估计

$$f(x) = \frac{\alpha x_m^\alpha}{x^{\alpha+1}}, \quad x \geq x_m$$ $$E[X] = \frac{\alpha x_m}{\alpha - 1} \quad (\alpha > 1)$$ $$\hat{x_m} = \min(X_i), \quad \hat{\alpha} = 1 + \frac{n \hat{x_m}}{\sum_{i=1}^n (X_i - \hat{x_m})}$$

2. 极大似然估计 (Maximum Likelihood Estimation)

似然函数：
$$L(\theta) = \prod_{i=1}^n f(x_i; \theta)$$ 对数似然函数：
$$\ell(\theta) = \sum_{i=1}^n \ln f(x_i; \theta)$$ MLE：
$$\hat{\theta}_{MLE} = \arg\max_\theta \ell(\theta)$$

极大似然估计计算器

指数分布MLE

$$\ell(\lambda) = n\ln\lambda - \lambda\sum_{i=1}^n x_i$$ $$\frac{d\ell}{d\lambda} = \frac{n}{\lambda} - \sum_{i=1}^n x_i = 0$$ $$\hat{\lambda}_{MLE} = \frac{n}{\sum_{i=1}^n x_i} = \frac{1}{\bar{x}}$$

伽马分布MLE

$$\ell(\alpha, \beta) = n\alpha\ln\beta - n\ln\Gamma(\alpha) + (\alpha-1)\sum_{i=1}^n\ln x_i - \beta\sum_{i=1}^n x_i$$ 需要数值方法求解

帕累托分布MLE

$$\ell(\alpha, x_m) = n\ln\alpha + n\alpha\ln x_m - (\alpha+1)\sum_{i=1}^n\ln x_i$$ $$\hat{x_m} = \min(X_i)$$ $$\hat{\alpha}_{MLE} = \frac{n}{\sum_{i=1}^n \ln(X_i/\hat{x_m})}$$

3. 分位数估计 (Quantile Estimation)

经验分位数：
$$\hat{q}_p = X_{(\lceil np \rceil)} \quad \text{或插值方法}$$ 理论分位数：
$$F(q_p) = p \Rightarrow q_p = F^{-1}(p)$$

4. 估计质量评价

无偏性 (Unbiasedness)

$$E[\hat{\theta}] = \theta$$

估计量的期望值等于真实参数值

一致性 (Consistency)

$$\hat{\theta}_n \xrightarrow{P} \theta \quad \text{当} \quad n \to \infty$$

随着样本量增加，估计量依概率收敛到真实值

均方误差 (Mean Squared Error)

$$MSE(\hat{\theta}) = E[(\hat{\theta} - \theta)^2] = \text{Var}(\hat{\theta}) + [\text{Bias}(\hat{\theta})]^2$$

衡量估计量的总体精度

5. 区间估计 (Interval Estimation)

置信区间：
$$P(L \leq \theta \leq U) = 1 - \alpha$$ 其中 $[L, U]$ 是 $(1-\alpha)$ 置信区间

置信区间计算器

正态分布置信区间

$$\bar{X} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}} \quad \text{(已知方差)}$$ $$\bar{X} \pm t_{\alpha/2, n-1} \frac{S}{\sqrt{n}} \quad \text{(未知方差)}$$

指数分布置信区间

$$\frac{2n\bar{X}}{\chi^2_{\alpha/2, 2n}} \leq \frac{1}{\lambda} \leq \frac{2n\bar{X}}{\chi^2_{1-\alpha/2, 2n}}$$

Bootstrap置信区间

百分位数方法：
$$[\hat{\theta}^*_{(\alpha/2)}, \hat{\theta}^*_{(1-\alpha/2)}]$$

6. 假设检验 (Hypothesis Testing)

基本框架：
$$H_0: \theta = \theta_0 \quad \text{vs} \quad H_1: \theta \neq \theta_0$$ 检验统计量：
$$T = \frac{\hat{\theta} - \theta_0}{\text{SE}(\hat{\theta})}$$

7. 估计方法比较

估计方法 优点 缺点 适用场景
矩估计 计算简单，直观易懂 效率较低，可能不唯一 初步估计，简单分布
极大似然估计 渐近最优，一致性好 计算复杂，可能无解析解 大样本，复杂分布
分位数估计 稳健性好，不依赖分布 信息利用不充分 异常值较多，非参数情况
Bootstrap 分布自由，适用性广 计算量大，依赖样本 复杂统计量，小样本
