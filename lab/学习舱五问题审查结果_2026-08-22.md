# 损失模型互动学习舱 · 五问题审查结果

审查时间：2026-08-22
审查方式：逐条对照项目代码（`损失模型互动学习舱/`）

## 1. 试验台三层联动感受不出来、不知道什么意思

**状态：✅ 已解决**

依据：
- `learn.html` 在实验台上方专门加了一行蓝色提示语——只要该知识点引擎带 `live` 回调，就显示：
  > "☝️ 拖动下方实验台的参数，②数学量 与 ③现实标签 会随之**实时变化**——这就是'三层联动'"
- 引擎每次重绘都会回调 `updateChainLive()`（learn.html），把「① 参数层 / ② 数学量 / ③ 现实现象」三个节点实时刷成新值（格式 `val|sub` 拆成主值+副注），并加 `.lit` 高亮脉冲（900ms）——你肉眼能看到三节点跟着滑块动。
- 全站 **52 个知识点全部具备** `chain:{param, math, real}` 三层结构（搜索 `chain` 命中 53 次含注释样例）。
- 其中 26 个知识点引擎带 `live` 回调（真·实时联动），其余不带 `live` 的引擎（如配对/拼装/预测类）通过 `input`/`click` 事件触发 `pulseChain()`——三节点从左到右依次点亮动画，依然能体现「参数→数学量→现实现象」的递进关系。

## 2. 图片展示过大，移动参数时看不全整个图片

**状态：✅ 已解决**

依据：
- `learn.html` 讲解区图片统一为 `.lec-img`：`width:100%; aspect-ratio:16/9; object-fit:contain`——图片**按容器等比缩放、完整包含**，不再撑满屏幕。要看大图点一下进 lightbox 全屏（`cursor:zoom-in`）。
- 讲解区视频+图片是**左右两栏并列**（`.lec-grid{grid-template-columns:1fr 1fr}`），单张图只占半栏宽；移动端（≤760px）自动塌成单列。
- 实验台画布 `.canvas-shell canvas{width:100%;height:auto}`，只在实验台那一栏（约半页宽）内自适应；散点图 `plotScatter` 尺寸封顶 `Math.min(..., 330px)`，保证拖参数时整张图都看得到。
- 图片资产按 README 记录「已 resize 到 1400px」（`img/`，39 张核心概念图 + Ch15 图集）。

## 3. 通关自测题目太少

**状态：✅ 已解决（每知识点 9 题，全站 468 题）**

依据：
- `course.js` 共 **52 个知识点、468 道自测题**（统计 `lv:` 字段 = 468，知识点 id = 52），即**每点 9 题**。
- 难度分三档 tab：🟢 简单×3 / 🟡 中等×3 / 🔴 困难×3（`lv`=1/2/3），每个 tab 带进度（0/3 → 答完变 ✓），九题全答完点亮该知识点（`learn.html` 的 `renderQuiz`）。
- Ch21（GLM 两个新点）与 Ch22（模拟方法 4 点）的 9 题分级自测也均已就位（README「9 题分级自测均已就位」）。
- 加题只需在 `course.js` 对应 kp 的 `quiz` 数组里追加带 `lv` 的题目，四个页面自动同步。

## 4. 拖拽题：答案不对不能拖——但有些拖过去就不能修改，应允许放回重选

**状态：✅ 已解决**

依据（`engine.js` 的两个拖拽引擎）：
- **配对引擎 `Engine.match`**：拖错 → 槽位闪红 700ms 后**自动清空并复位成「放置处」**，右侧的卡片项**不会消失**，可重新拖拽再选（只在对时才从右侧移除并锁定）。所以「拖错了」永远可以重选。
- **公式拼装引擎 `build`**：顶部直觉提示明写「💡 拖入按顺序排列 · **点击已放入的积木可取回重排**」——已放入的积木带 `onclick`，点击即从拼装区取回银行重新选择。
- 竞技场「配对冲刺」（arena.html）同样：拖错只是闪红、卡片留在右侧，可再拖；拖对才锁定。
- 唯一锁定不可改的是「已配对正确」的项——这属于预期行为（配对正确无需改）。

## 5. 竞技场题目与已建内容不匹配（如 Spearman 没讲却出现）+ 学哪练哪 + 最后放综合竞技场

**状态：✅ 已解决**

依据（`arena.html` + `game.js`）：
- 竞技场菜单顶部新增**训练范围选择**，标题就是 **「🎯 训练范围 · 学哪练哪」**：
  - **「已学内容」**（默认高亮，`SCOPE={onlyDone:true}`）：只出你**已点亮知识点**的题（`allQuiz({onlyDone})` 过滤）。所以 Spearman 在对应知识点被学过之前**不会再出现**。
  - **逐章芯片**（Ch13～Ch22）：只练选中那一章。
  - **「综合（全部已建设）」**：单独一个可选芯片，对应你说的「全建好后再放综合竞技场」——它是**选入**而非默认，改成「全部已建设」，不强制混入未讲内容。
  - 底部实时显示当前范围题库数（如「当前范围题库：N 题」）。
- 竞技场题库**自动同步** `course.js`（`Game.allQuiz()` 从所有 kp.quiz 汇总），加章/加点/加题后竞技场不用改代码。
- 「配对冲刺」也尊重同一训练范围（`startMatchSprint` 按 `SCOPE` 过滤）。
